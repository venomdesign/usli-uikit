Components / Accordion

Accordion

Collapsible stacked sections. Project usli-accordion-item children into usli-accordion, each keyed by a unique value.

Basic usage

By default only one panel can be open at a time — opening a new one closes the previous. Bind [(expanded)] to control it from outside.

A shared Angular component library built on Bootstrap. Add the ui-sdk package as a dependency and import the components you need. Yes — components accept a variant input matching the Button color palette. 
<usli-accordion>
  <usli-accordion-item value="a" label="What is USLI UI Kit?">
    A shared Angular component library built on Bootstrap.
  </usli-accordion-item>
  <usli-accordion-item value="b" label="How do I install it?">
    Add the ui-sdk package as a dependency and import the components you need.
  </usli-accordion-item>
</usli-accordion>

Multiple mode

Set multiple to allow more than one panel open at once. The bound value becomes an array of the open panels' values.

Panels can be opened independently in multiple mode. This panel stays open even if you open another one. 
<usli-accordion [multiple]="true" variant="primary">
  <usli-accordion-item value="x" label="First panel">
    Panels can be opened independently in multiple mode.
  </usli-accordion-item>
  <usli-accordion-item value="y" label="Second panel">
    This panel stays open even if you open another one.
  </usli-accordion-item>
</usli-accordion>

API

usli-accordion

NameTypeDefaultDescription
multiple boolean false Allows more than one panel to be expanded at once.
expanded unknown | unknown[] undefined Two-way bindable via [(expanded)]. A single value in single-open mode, or an array of values when multiple is true.
variant 'primary' | 'secondary' | 'tertiary' | 'error' | 'warning' | 'info' | 'success' | undefined undefined Optional accent color applied to each item's expanded state.

usli-accordion-item

NameTypeDefaultDescription
value unknown required Unique value identifying this item.
label string required Text shown in the item's header button.
disabled boolean false Prevents expansion via click.
